
# Ozon-scraper, Сбор данных товаров

Программа собирает данные по ссылкам и обрабатывает страницы параллельно, что ускоряет получение результатов.


## Возможности

- Парсинг товаров с Ozon по ссылкам
- Параллельная обработка страниц (ускоренный сбор данных)
- Получение:
  - цены
  - старой цены
  - скидки
  - рейтинга
  - количества отзывов
- Выгрузка данных в:
  - JSON
  - CSV
  - XLSX

## Установка

Установите Python 3.10+  
https://www.python.org/downloads/

Скачайте проект:

```bash
git clone https://github.com/BlackRaisons/Ozon-scraper.git
```

Перейдите в папку проекта:

```bash
cd Ozon-scraper
```


Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Откройте 2 разных терминала. В одном запустите api-сервера, в другом интерфейс

1. Запуск API сервера
   ```bash
    uvicorn Api.api:app --host 127.0.0.1 --port 8000 --reload
   ```

2.   Запуск интерфейса
   ```bash
    streamlit run Gui/gui.py
   ```

После запуска интерфейс вас автоматически перекинет в окно с парсером, если же этого не произошло, то перейдите по этой ссылке:

http://localhost:8501


## Как пользоваться

 В окне парсера можно вставить не ограниченное кол-во ссылок, но работать будут 3 из них одновременно, это сделано для того, чтобы озон не обнаружил бота
 Как только одна из 3 ссылок отработала, начинает работать другая

ССЫЛКИ ВЫ НАСТРАИВАЕТЕ САМИ, на озоне, чем точнее вы настроити ссылки, тем точнее будут результаты. Настраиваете вы их на сайте озон, в фильтрах

Далее просто копируете ссылку(и) и вставляете специальное окно, выставляете лимит(сколько карточек товара собрать),
max означает по максимум, пока не кончатся карточки.
нажимаете старт, и ждете заврешения работы. Первый запуск может занимать 5 минут, т.к подкачивается компонент, необходимый для работы парсера
В конце вам предложат сохранить данные в разных форматах


##  Как выйти с программы?

Для того, чтобы выйти с программы, достатоточно просто закрыть работающие терминалы, однако рекомендую перед закрытием, прожать в окне терминала комбинацию клавишь ctrl + c, это явно останавливает программу
