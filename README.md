
# Ozon-scraper, Сбор данных товаров

Программа собирает данные по ссылкам и обрабатывает страницы параллельно, что ускоряет получение результатов.


## Возможности

- Парсинг товаров с Ozon по ссылкам
- Параллельная обработка страниц (ускоренный сбор данных)
- Получение:
  - цены
  - старой цены
  - скидки
  - рейтинга
  - количества отзывов
- Выгрузка данных в:
  - JSON
  - CSV
  - XLSX

## Установка

Установите Python 3.10+  
https://www.python.org/downloads/

Скачайте проект:

```bash
git clone https://github.com/BlackRaisons/Ozon-scraper.git
```

Перейдите в папку проекта:

```bash
cd Ozon-scraper
```


Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Откройте два разных терминала. В одном запустите API-сервер, в другом — интерфейс.

1. Запуск API сервера
   ```bash
    uvicorn Api.api:app --host 127.0.0.1 --port 8000 --reload
   ```

2.   Запуск интерфейса
   ```bash
    streamlit run Gui/gui.py
   ```

После запуска интерфейс автоматически откроется в браузере.
Если этого не произошло, перейдите по ссылке:
http://localhost:8501


## Как пользоваться

В окне парсера можно вставить неограниченное количество ссылок, но одновременно обрабатываются только 3 из них. Это сделано для того, чтобы снизить вероятность обнаружения со стороны Ozon.
Как только одна из ссылок обработана, начинается обработка следующей.
Ссылки вы настраиваете самостоятельно на сайте Ozon через фильтры. Чем точнее настроены фильтры, тем точнее будут результаты.

Далее:
скопируйте ссылки
вставьте их в соответствующее поле
укажите лимит (сколько карточек товаров нужно собрать)

Параметр max означает сбор всех доступных товаров, пока они не закончатся.

Нажмите запуск и дождитесь завершения работы. Первый запуск может занимать до 5 минут, так как происходит загрузка необходимых компонентов.
После завершения работы вам будет предложено сохранить данные в одном из доступных форматов.

##  Как выйти с программы?

Для того, чтобы выйти с программы, достатоточно просто закрыть работающие терминалы, однако рекомендую перед закрытием, прожать в окне терминала комбинацию клавишь ctrl + c, это явно останавливает программу
