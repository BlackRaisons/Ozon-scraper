# Ozon Parser Pro

Приложение для простого сбора товаров с Ozon.

Без технической магии: вставили ссылки, нажали кнопку, получили таблицу и скачали файл.

## Что умеет
- Парарельная работа страниц(сбор информации)
- Собирает товары по ссылкам Ozon
- Показывает актуальную цену, старую цену, скидку, рейтинг и отзывы
- Отображение результатов
- Даёт скачать результат в `JSON`, `CSV` или `XLSX`

## Как запустить

Нужен Python 3.10+.
Его вы можете скачаь с официального сайта https://www.python.org/downloads/

### 1) Установить пайтон

Нужен Python 3.10+.
Его вы можете скачаь с официального сайта https://www.python.org/downloads/

### 2)  Установите необходимые библиотеки

Перейдите в папку проекта 

```bash
cd С:/ваш/путь/до/папки/проекта
```
установите необходимые библиотеки

```bash
pip install -r requirements.txt
```


### 1) Запустить сервер

```bash
uvicorn Api.api:app --host 127.0.0.1 --port 8000 --reload
```

### 2) Запустить интерфейс

```bash
streamlit run Gui/gui.py
```

После этого откройте в браузере адрес, который покажет Streamlit  
(обычно `http://localhost:8501`).

## Как пользоваться

1. Вставьте одну или несколько ссылок Ozon.
2. Укажите лимит товаров (или включите MAX).
3. Нажмите кнопку запуска.
4. Дождитесь завершения.
5. Скачайте результат в нужном формате.

## Если что-то не работает

- Перезапустите оба процесса (сервер и интерфейс).
(Это можно сделать  нажав комбинацию клавишь ctrl + c)
- Убедитесь, что сервер запущен на `127.0.0.1:8000`.
- Попробуйте сначала небольшой лимит (20-50 товаров).
- Если долго грузится, просто подождите: парсинг может занимать несколько минут.



- Сайт может меняться, поэтому иногда парсер может работать нестабильно.
- Используйте инструмент в рамках правил сайта и законодательства.
